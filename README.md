# Gourmet Fine Pastries

![Gourmet Fine Pastries homepage](gourmet_ss.jpeg)

**Gourmet Fine Pastries** — an online ordering app for a bakery, including custom cake orders for special events. Customers order online for pickup or delivery, with managers and drivers coordinating in real time.

### Features
- Online ordering for cakes and pastries
- Custom cake builder for events
- Pickup and delivery options
- Live order notifications
- Manager dashboard with real-time orders and driver assignment
- Driver dashboard showing assigned deliveries live

*Built for a client — source code kept private.*
